LENTERA — a lantern spirit defends the night sky in an original sumi-e ink arcade shooter. Shadow wisps descend in waves; shoot light orbs, chain combos for a multiplier, catch power-ups, and face a great shadow boss every third wave. Painted entirely in black ink on rice paper, with one vermilion seal red for the lantern, the power-ups and the key UI. Mouse or WASD to move, hold click or SPACE to fire, P to pause, M to mute, R to restart.

## Run it

```sh
python3 -m http.server 8080 --directory game
```
